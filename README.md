# Blackjack · entraînement à la stratégie de base

Jeu de blackjack en un seul fichier (`index.html`, sans dépendance) pour s'entraîner à appliquer la stratégie de base optimale. Après chaque décision, un badge indique si le choix était le bon, sans interrompre la partie.

## Règles
6 decks, le croupier reste sur tous les 17, blackjack payé 3:2, peek du croupier, double autorisé après split, split jusqu'à 4 mains, un seul tirage sur les as séparés, pas d'assurance ni de reddition.

## Fonctionnalités
- Indicateur ✓ / ✗ avec explication après chaque décision, indice optionnel avant de jouer
- Historique, statistiques (précision, série, erreurs fréquentes par type de main), sauvegardées dans le navigateur
- Modes d'entraînement : paires, soft, doubler ou pas, dur 12-16, et « mes points faibles » (adaptés à chaque joueur)
- Jusqu'à 4 joueurs à la table, chacun avec son prénom, sa mise, son solde et ses stats, contre le même croupier
- Table de stratégie de base consultable dans le jeu
- Raccourcis clavier : T tirer, R rester, D doubler, S séparer, Espace nouvelle main

## Utilisation
Ouvrir `index.html` dans un navigateur, ou activer GitHub Pages (Settings → Pages → branche `main`, dossier `/ (root)`).
